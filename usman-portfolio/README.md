# Muhammad Usman — Portfolio

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — website content and project links
- `style.css` — blue/black design, responsive layout, floating animations
- `script.js` — mobile navigation, rotating hero title, automatic accent-colour changes
- `assets/profile.jpg` — profile photo

## Add your live project links
Open `index.html` in VS Code. Search for `https://example.com/` and replace each sample link with the real URL for that project:
- NASA Landing Page
- Budget App
- E-commerce Website
- Berry Admin Panel
- Amazon Clone

The website will open each link in a new tab after you replace the sample URL. The sample links are placeholders and do not point to your projects.

## Add your email
Search for `your-email@example.com` in `index.html` and replace it with your real email address.

## Run locally
Open the folder in VS Code and use the Live Server extension on `index.html`, or open `index.html` directly in a browser.

## Deploy
Upload the folder to a GitHub repository and import it into Vercel, or use Netlify Drop. No build command is needed.
